# Security policy

The supported release line is `0.1.x`. Please do not disclose vulnerabilities in a public issue. Use [GitHub private vulnerability reporting](https://github.com/anisahaya/model-router/security/advisories/new), including reproduction steps, affected version, platform, and a minimal proof of concept. We will acknowledge reports and coordinate a fix and disclosure timeline.

Do not include credentials, API keys, or private customer data in reports.
