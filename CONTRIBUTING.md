# Contributing

1. Install Node.js 22 or 24 and pnpm 11.
2. Run `pnpm install --frozen-lockfile`.
3. Make a focused change and add tests for behavior changes.
4. Run `pnpm run verify` before opening a pull request.

Pull requests should explain platform impact, preserve workspace package names and `MODEL_ROUTER_*` interfaces, and never include credentials or generated local state. Please use the issue tracker for bugs and feature proposals.
