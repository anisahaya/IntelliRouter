# Support

Start with `intellirouter doctor --harness <name>` and include its JSON output (after removing secrets), Node version, operating system, and installation method in a [GitHub issue](https://github.com/anisahaya/model-router/issues).

Supported combinations are macOS, Linux, and Windows with Node.js 22 or 24. Native harnesses are optional integrations and must be installed and authenticated separately. Pi currently reports as unavailable until its native adapter ships. Security issues belong in [SECURITY.md](SECURITY.md), not public issues.
